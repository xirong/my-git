# v2.0.0: Modern Git & AI-Native Engineering Handbook

English | [中文](../release-notes-v2.0.0.md)

## Highlights

- Updated repository positioning to focus on Git / GitHub practical scenarios for modern engineering teams and the AI programming era.
- Added AI Native Git Workflow, AI Code Review, and practical AI change review examples.
- Added Team Git Workflow Guide covering GitHub Flow, GitLab Flow, Gitflow, Trunk-Based Development, Release Branches, etc.
- Added GitHub Engineering Governance content covering branch protection, Rulesets, CODEOWNERS, Merge Queue, Actions, Release, and security scanning.
- Added Git Troubleshooting Playbook covering common issues like incorrect commits, reset, rebase, force push, and secrets committed to history.
- Added Large Repository practices covering partial clone, sparse checkout, Git LFS, worktree, and repo maintenance.
- Added reusable templates including PR, Issue, Code Review, AI Review, commit message, release note, hotfix, and branch naming.
- Added Company Engineering Practices directory, curating engineering experiences from Google, Microsoft, Meta, Uber, Netflix, Shopify, Slack, etc., using public materials.

## Why v2.0

v2.0 focuses on three major shifts:

1. Git usage has expanded from individual command learning to team collaboration, review, release, recovery, and engineering governance.
2. AI programming enables faster code generation, making diff reviews, commit splitting, validation, and rollbacks even more critical.
3. Engineering teams need more directly applicable Git / GitHub collaboration templates and decision-making paths.

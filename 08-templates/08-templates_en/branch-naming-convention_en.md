# Branch Naming Convention

English | [中文](../branch-naming-convention.md)

## Format

```text
<type>/<short-description>
```

## Types

- `feat/`
- `fix/`
- `docs/`
- `refactor/`
- `test/`
- `chore/`
- `hotfix/`
- `release/`
- `ai/`

## Examples

```text
feat/github-governance-guide
fix/recover-lost-commit-example
docs/ai-native-git-workflow
hotfix/remove-broken-link
ai/review-large-repo-guide
```

## Rules

- Use lowercase English
- Use `-` to separate words
- The branch name should express the intent of the task
- Avoid untrackable names like `test`, `tmp`, or `new`

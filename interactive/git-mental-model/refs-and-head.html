引用与 HEAD

下一次 commit 会移动谁？

HEAD 的形式决定 branch 前移，还是只有 detached 指针移动。

附着与 detached，保留下来的名字不同。

branch 和 tag 都是给对象命名的引用。附着的 HEAD 指向 branch，detached HEAD 直接指向 commit。先选择条件并预测哪条引用会移动，再播放五步模型。

C1-C4 与 T1 是示意 ID。链接实验会检查真实对象 ID 与引用内容。

静态模型：HEAD -> main -> C3；agent/draft -> C2；v1-light -> C1；v1-annotated -> T1(tag) -> C1。附着提交会前移 main；detached 提交只前移 HEAD，直到新 branch 给它命名。
预测：detached 状态提交后，main 与 HEAD 各指向哪里？

HEAD 直接指向新 C4；main 仍指向 C3。若需要明确保留该提交，离开前在 C4 创建 keep-detached。

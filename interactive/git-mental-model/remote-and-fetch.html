远端与 Fetch

fetch 之后，本地文件变了吗？

fetch 更新本地远端跟踪引用；整合才更新检出状态。

看见 B，与检出 B，是两个动作。

writer 把 B 推到临时 bare origin。比较只做 fetch 与显式前移 reader/main。分别观察 main、origin/main、Index 与 Working Tree。

A 与 B 是示意 commit 标识。实验会创建真实 bare 仓库与两个 clone。

静态模型：fetch 后，origin/main 从 A 前移到 B，main、Index 与 Working Tree 仍在 A/version=1。显式执行 merge --ff-only origin/main 后，它们才到 B/version=2。
预测：只执行 fetch 后，story.txt 是什么？

version=1。origin/main 在本地记录 B，但当前 main、Index 与 Working Tree 仍在 A。

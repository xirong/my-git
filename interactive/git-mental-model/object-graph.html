Git 保存的是对象图： blob / tree / commit

内容、名字与提交说明分别属于不同对象。沿六个状态建立一个真实的小仓库，看清每一条边由谁保存。

构建序列

每一步都来自同一个仓库状态模型。

    职责边界

    blob
    只保存文件原始内容，不保存文件名。
    tree
    保存模式、名字和子对象 ID。
    commit
    保存根 tree、父提交、作者/提交者与消息。

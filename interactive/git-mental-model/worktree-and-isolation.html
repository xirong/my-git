Worktree 与隔离

worktree 到底隔离了什么？

linked worktree 共享 Git 历史，同时分开每处检出状态。

对象共享，草稿分开。

比较重复检出 main 与分配独立 feature 分支。成功建立的每个 worktree 都有独立 HEAD、Index 和文件，但普通 refs 与 objects 仍共享。

图示表达归属边界，不表示文件系统大小或并发写入顺序。

静态模型：objects 与普通 refs 共享；HEAD、Index 与 Working Tree 分开。Git 拒绝重复检出 main，但允许不同 feature 分支。端口、数据库与 Git 外文件不受隔离。
预测：feature worktree 暂存文件，会改变 primary 的 Index 吗？

不会，两处 Index 分开。提交创建后，其对象会通过共享对象库与引用被另一处看到。

English | [中文](../deprecated-resources.md)

This page records content that still has historical reference value but is not recommended as a primary learning path.

## Why We Need an Archive Page

Git, GitHub, GitLab, and team collaboration tools are constantly evolving. The commands, screenshots, tool recommendations, and platform feature descriptions in old articles might no longer be suitable to follow directly.

Archiving does not mean the content has no value; it is mainly used to:

- Understand historical background
- Compare the differences between old and new workflows
- Preserve migration clues
- Prevent readers from treating old practices as currently recommended solutions

## Reading Suggestions

When reading archived content, prioritize confirming three things:

1. Whether the commands are still applicable in the current Git version
2. Whether the platform features still exist in current GitHub / GitLab
3. Whether the recommended workflow suits the current team size and release method
